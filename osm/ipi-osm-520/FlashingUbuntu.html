Boot Switch Setting

Before flashing, set the boot switch SW1403 to Download Mode:

Cable Connections

  • Power: Connect the power cable to the board power connector.
  • USB (Flash): Connect a Micro-USB cable from the board’s flash port to your host machine.

If the board does not automatically enter Download Mode, manually reset it by toggling the power. Flashing will begin automatically once the board is detected.

Note: SW1403 sets the boot mode (Download Mode), while SW1401 is the power switch used to reset the board after the boot mode has been set.

Expected Output

The flow detects the MediaTek SoC ( hw_code 0x8189 ), erases the boot areas, then flashes each partition
defined in ubuntu.json. A successful run ends with Rebooting OKAY.

Flashing is complete once you see Rebooting OKAY at the end of the output. The board reboots automatically into Ubuntu 24.04 (Noble) after flashing finishes.

After flashing: return SW1403 to its normal (non-download) boot position before the next power cycle, so the board boots from UFS instead of re-entering Download Mode.(0011)
